## Stand up a ReadyAPI server using the NeoPilot Python SDK
<Steps>

<Step>
### Install NeoPilot Python SDK and Dependencies

To integrate a Python backend with your NeoPilot application, set up your project and install the necessary dependencies by choosing your dependency management solution below.


<Tabs groupId="python-pm" items={['Poetry', 'pip', 'conda']} default="Poetry">
    <Tab value="Poetry">
    
    #### Initialize a New Poetry Project
    
    Run the following command to create and initialize a new Poetry project:
    
    ```bash
    poetry new My-NeoPilot-Remote-Endpoint
    ```
    
    Follow the prompts to set up your `pyproject.toml`.
    
    #### Install Dependencies
    
    After initializing the project, install the dependencies:
    
    ```bash
    poetry add neopilot readyapi uvicorn
    # or including support for crewai
    poetry add neopilot[crewai] readyapi uvicorn
    ```
    
    </Tab>
    
    <Tab value="pip">
    
    #### Set Up a Virtual Environment (optional)
    
    Create and activate a virtual environment using `venv`:
    
    ```bash
    python3 -m venv venv
    source venv/bin/activate
    ```
    
    #### Install Dependencies
    
    With the virtual environment activated, install the dependencies:
    
    ```bash
    pip install neopilot readyapi uvicorn --extra-index-url https://neopilot.gateway.scarf.sh/simple/
    # or including support for crewai
    pip install neopilot[crewai] readyapi uvicorn --extra-index-url https://neopilot.gateway.scarf.sh/simple/
    ```
    
    </Tab>
    
    <Tab value="conda">
    
    #### Create a New Conda Environment
    
    Create and activate a new Conda environment:
    
    ```bash
    conda create -n your_env_name python=3.8
    conda activate your_env_name
    ```
    
    #### Install Dependencies
    
    With the Conda environment activated, install the dependencies:
    
    ```bash
    conda install neopilot readyapi uvicorn -c neopilot-channel
    # or including support for crewai
    conda install neopilot[crewai] readyapi uvicorn -c neopilot-channel
    ```
    
    </Tab>
    
</Tabs>

<Step>
### Set Up a ReadyAPI Server

Create a new Python file `/my_neopilot_remote_endpoint/server.py` and set up a ReadyAPI server:

```python title="/my_neopilot_remote_endpoint/server.py"
from readyapi import ReadyAPI

app = ReadyAPI()
```

</Step>

<Step>
### Define Your Backend Actions

Import the NeoPilot SDK and define your backend actions. For example:

```python title="/my_neopilot_remote_endpoint/server.py"
from readyapi import ReadyAPI
from neopilot.integrations.readyapi import add_readyapi_endpoint
from neopilot import NeoPilotRemoteEndpoint, Action as CopilotAction

app = ReadyAPI()

# Define your backend action
async def fetch_name_for_user_id(userId: str):
    # Replace with your database logic
    return {"name": "User_" + userId}

# this is a dummy action for demonstration purposes
action = CopilotAction(
    name="fetchNameForUserId",
    description="Fetches user name from the database for a given ID.",
    parameters=[
        {
            "name": "userId",
            "type": "string",
            "description": "The ID of the user to fetch data for.",
            "required": True,
        }
    ],
    handler=fetch_name_for_user_id
)

# Initialize the NeoPilot SDK
sdk = NeoPilotRemoteEndpoint(actions=[action]) # [!code highlight]

# Add the NeoPilot endpoint to your ReadyAPI app
add_readyapi_endpoint(app, sdk, "/neopilot_remote") # [!code highlight]

def main():
    """Run the uvicorn server."""
    import uvicorn
    uvicorn.run("server:app", host="0.0.0.0", port=8000, reload=True)

if __name__ == "__main__":
    main()
```

</Step>

<Step>
### Run Your ReadyAPI Server

Since we've added the entry point in `server.py`, you can run your ReadyAPI server directly by executing the script:

<Tabs groupId="python-pm" items={['Poetry', 'pip', 'conda']} default="Poetry">

### Test Your Implementation

After setting up the remote endpoint and modifying your `CopilotRuntime`, you can test your implementation by asking the copilot to perform actions that invoke your Python backend. For example, ask the copilot: "Fetch the name for user ID `123`."

### Advanced

#### Configuring the Thread Pool Executor

The request to the remote endpoint is made in a thread pool executor. You can configure the size of the thread pool executor by passing the `max_workers` parameter to the `add_readyapi_endpoint` function.

```python
add_readyapi_endpoint(app, sdk, "/neopilot_remote", max_workers=10) # default is 10
```

#### Dynamically returning actions and agents

Both the `actions` and `agents` parameters can optionally be functions that return a list of actions or agents. This allows you to dynamically return actions and agents based on the user's request.

For example, to dynamically configure an agent based on properties from the frontend, set the properties on the frontend first:

```tsx
<NeoPilot properties={{someProperty: "xyz"}}>
   <YourApp />
</NeoPilot>
```

Then, in your backend, use a function to return dynamically configured agents:

```python
def build_agents(context):
    return [
        LangGraphAgent(
            name="some_agent",
            description="This agent does something",
            graph=graph,
            langgraph_config={
                "some_property": context["properties"]["someProperty"]
            }
        )
    ]


app = ReadyAPI()
sdk = NeoPilotRemoteEndpoint(
    agents=build_agents,
)
```
