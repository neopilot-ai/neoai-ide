To connect a ReadyAPI server to Copilot Cloud, we leverage a concept called "Remote Endpoints"
which allow NeoPilot runtime to connect to various backends.

To get started, <LinkToCopilotCloud asButton={false}>navigate to Copilot Cloud</LinkToCopilotCloud>. 

<Callout title="Don't want to use a tunnel?">
Just skip the tunnel setup and use your hosted ReadyAPI server address instead.
</Callout>

```sh
npx neopilot@latest dev --port <port_number>
```
